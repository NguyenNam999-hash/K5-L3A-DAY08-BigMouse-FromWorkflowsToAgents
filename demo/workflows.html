Each shape handles the same refund claim by a different route. This page shows the whole decision space: every entry branch, every exit, the host write gate they share, and what each outcome does to the ledger and the audit trail. The run-by-run view lives on the demo page.

Shape A

Deterministic workflow

Fixed Python steps. The model may draft reply text but never chooses the amount or writes the ledger.

Shape B

Single ReAct agent

One bounded reasoning loop, at most eight steps. The agent may call read tools; only the host commits.

Shape C

Orchestrator and investigators

An allowlist handoff feeds read-only investigators. The orchestrator quotes; investigators cannot write.

Shape D

Reference swarm

Peers parse the ticket, then read-only investigators quote. One seed in five trusts the ticket delay; that weakness is marked, not hidden.

Shared boundary

Host write gate

Every positive quote ends here. Approval, ownership, the per-order cap, idempotency, and the crash points are host decisions that model output cannot skip.
